# @plasius/glob

Bounded glob matching for Plasius build tooling, using minimatch's nonrecursive
matching engine. The package replaces the picomatch implementation in approved
consumer dependency graphs. It does not claim every picomatch API or option.

Development and rollout are tracked in [Task #1](https://github.com/Plasius-LTD/glob/issues/1).
See the [design](docs/design/build-tool-glob-compatibility.md) for compatibility,
security, validation and publishing requirements. No release is available yet.
