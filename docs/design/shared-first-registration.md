## Initial registration contract (historical)

First registration requires explicit `first_publication=true` on main `cd.yml`,
exact successful commit CI, production environment, hosted publication, a sealed
artifact, fresh main, provenance and anonymous registry HTTP404. Its one isolated
step reads the standard one-day `NPM_TOKEN`, scoped to package write with publishing
2FA bypass and no organisation-management permission. No local publication, new
secret name, placeholder package or automatic token fallback is permitted.

After verified registry integrity and packed consumers, configure npm trust for
`Plasius-LTD/glob`, workflow `cd.yml`, environment `production`, allowing direct
publishing. Remove the enrollment descriptor through review and verify ordinary
OIDC publication within the binding's two-day first-use window. Remove/revoke the
temporary credential when all intended registrations are done. A missing enrollment
refuses first registration even if the registry later returns HTTP404.

The portable shared Node tests exercise exact admission, errors, forwarding,
immutable artifacts and actual shell credential cleanup. Existing package tests,
privacy, lint, type checks, build, audit and pack checks remain required. Node
helper coverage and the package LCOV are combined without lowering thresholds.

Glob must be registered and its published replacement adopted before the three
arcade packages' release; the current source and qualification owners retain their
gates. Registration alone does not qualify a game or publish site content.
